## 4. Failure Handling & Resolution (Phase 3)

1. **Initial Issue:**  
   When running `GPT2CausalLM.from_preset("gpt2_base_en")`, KerasHub attempted an HTTP request to `api.kaggle.com`. Inside restricted network/sandbox environments, this triggers `NameResolutionError ([Errno 8])`.
2. **Investigation:**  
   Inspection revealed that the full 475 MB `model.weights.h5` and tokenizer vocabulary had already been downloaded to your Mac user cache (`~/.cache/kagglehub/models/keras/gpt2/keras/gpt2_base_en/3`).
3. **Resolution:**  
   Updated [`scripts/check_gpt2.py`](file:///Users/snehagupta/Downloads/Recipe_genai/scripts/check_gpt2.py) to check the local KaggleHub cache directory first. If local weights exist, it loads directly from the local directory without network latency or errors. If absent, it queries the remote preset name.
4. **Result:** Execution completed with exit code 0.
